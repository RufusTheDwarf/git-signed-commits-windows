# Contributing

Thanks for your interest! Here's how to suggest an improvement.

## Reporting a problem

Open an **issue** describing:
- your operating system and Git version,
- what you tried,
- expected vs. actual result,
- error messages (without tokens or private keys).

## Suggesting a change

1. Fork the repository.
2. Create a branch: `git switch -c fix/my-fix`.
3. Commit **signed** (this repo is about signing, so let's practice 😉):
   ```bash
   git commit -S -m "fix: correct ..."
   ```
4. Push and open a **pull request**.

## Style

- Clean Markdown, clear headings.
- Code blocks with language specified (`bash`, `powershell`, `markdown`…).
- No secrets, tokens, or keys in the examples.
